01

设计原则

四条约束，用于在具体实现出现分歧时做取舍。

P—01

克制的对比

层级优先由字重、字距与留白建立。颜色只用来标记状态与可操作性，不作为装饰手段。

P—02

一个强调色

主色只出现在可操作元素与当前状态上，单屏出现不超过两处。铜金仅用于编号与分隔等结构性点缀。

P—03

可预测的密度

间距一律取 4px 的倍数，桌面默认 8px 节奏。不允许出现 13px、27px 这类脱离阶梯的数值。

P—04

状态先于装饰

每个可交互元素必须完整定义 hover、focus、active、disabled 四态。缺态的组件不允许合入主干。

08

可访问性

以下条目为合入前必须通过的检查项。

对比度

  • 正文文字与背景 ≥ 4.5:1
  • 大字号（≥ 21px 或 17px 粗体）≥ 3:1
  • 图标与描边等非文本元素 ≥ 3:1
  • 禁用态可低于标准，但需同时具备指针与语义标记

焦点与键盘

  • 焦点环使用 --ring，不得用 outline: none 直接移除
  • Tab 顺序与视觉顺序一致，弹层内需做焦点捕获
  • Dialog 打开后焦点落入首个可操作元素，Esc 关闭
  • 所有纯图标按钮必须提供 aria-label

动效偏好

  • 响应 prefers-reduced-motion，关闭位移与缩放
  • 闪烁类动画频率不得高于 3 次 / 秒
  • 加载指示必须同时提供文本或进度语义

语义与结构

  • 表单控件与 label 通过 for / id 关联
  • 错误信息用 aria-describedby 绑定到输入框
  • 表格使用 thead / th，数值列声明对齐
  • 不使用颜色作为唯一的状态区分手段
09

使用规范

评审时最常见的两类分歧，以及约定好的处理方式。

这样做

  • 组件内只引用 --accent 等语义变量，主题切换零改动。
  • 主操作在单个视图中只出现一次，其余操作降级为次要或幽灵样式。
  • 间距取 --space-* 阶梯值，布局用 Grid，不靠 margin 堆叠。
  • 表格数值列右对齐并开启 font-variant-numeric: tabular-nums。
  • 浮层阴影使用 --shadow-2 或 --shadow-3，常规面板不加阴影。

不要这样

  • 在组件里写死十六进制色值或直接引用原始色阶。
  • 用颜色作为唯一的状态表达，缺少图标或文案。
  • 出现 13px、27px 这类脱离间距阶梯的数值。
  • 给每张卡片加左侧彩色描边，或让整页铺满渐变。
  • 用 outline: none 移除焦点环而不提供替代方案。
